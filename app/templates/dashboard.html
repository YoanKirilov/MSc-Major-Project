Only scan a private network you own or have permission to assess. Light checks the detected local network; Deep requires one explicit host and performs exhaustive service/version identification plus safe service checks. It does not use exploit or password-guessing checks.

Light checks fewer features, but can still take several minutes on a network with many devices. Devices that respond slowly and local AI preparation can add time. Progress is saved as checks finish.

What does each scan check?

Light checks 12 TCP and 3 UDP ports across the authorised network. Deep checks all 65,535 TCP ports and 25 selected UDP ports on one authorised device, with software identification and safe service checks. It can take substantially longer. Neither scan checks every possible security problem or proves a device is safe.
